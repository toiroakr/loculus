# Perry のサイズ・速度比較

Perry v0.5.1520（GitHub latest を 2026-10-11 に確認）、Node v24.13.0、Apple M3 / arm64。Zod 4.6.5、Valibot 1.5.0。

Perry は単独で動く macOS ARM64 実行ファイル。Node は同一内容の事前生成済み .mjs を実行。Zod は jitless、loculus も opt-in compile を使っていない。検証結果が Node と一致した構成だけ速度を掲載。

サイズは共通ランタイム＋スキーマ＋検証・計測プログラムを含む。ライブラリなしの基準は 14.917 MB / gzip 6.402 MB。配布済みランタイムをリンクしており、Perry のソースからのランタイムサイズ最適化は実行できていない。JS ライブラリ単体のバンドルサイズとは別の数値。MB は 1,000,000 bytes。

Zod の1ファイル版は `Error.captureStackTrace` の確認で停止。通常 import 版は未解決の `_validateAsync` シンボルでリンク失敗した。ソースのパッチや検証の削除はしていない。単純な Error の確認コードは成功するため、Error 全般の未対応と断定しない。

3プロセス × 7ラウンド、warmup 10,000。strings-3/CLI は1ラウンド50,000操作、strings-30は10,000操作。生サンプル・min/max・全プローブ・各ビルドの診断・ハッシュは results.json に保存。速度は今回の入力・ビルド設定に限る。Perry の全機能やすべての loculus スキーマへの対応を保証する試験ではない。
