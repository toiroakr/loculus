02 / DESIGN
An API shaped
by your inputs.
Many CLIs and forms work with names and strings. Loculus brings conversion, constraints, and missing-value handling together in one definition.


01
Give strings a clear meaning
"false" becomes false. number() treats an empty string as null for presence and defaults. Whitespace remains invalid. Accepted input formats are explicit, rather than relying on JavaScript truthiness or Number().


02
Constraints and presence as options
Write string({ min: 1, optional: true }). No layers of optional, nullable, and default wrappers. Use gt / gte / lt / lte for exclusive and inclusive numeric bounds.


03
Reject unexpected input by default
object() defaults to strict, catching misspelled options and unknown keys. Explicitly choose strip to discard extra keys, or passthrough to keep them.


04
Count the cost of using it once
For a CLI or form submission, schema construction is part of the work. Loculus optimizes construction plus one validation. Reuse the same schema when you need repeated validation.

Bounds, repeated values, and errors
l.string({ trim: true, min: 1, max: 80 });
l.number({ gt: 0, lte: 100 });
l.array(l.string());
l.array(l.string(), { wrapScalar: true });

const result = l.safeParse(query, input);
if (result.issues) {
  console.log(result.issues);
} else {
  console.log(result.value);
}


gt / lt exclude the bound; gte / lte include it. array() accepts only arrays by default. Set wrapScalar: true to wrap a single value in a one-element array.
safeParse returns { value } or { issues }. parse throws ValidationError on failure. Constraints stop at the first error within each field; errors from sibling fields are collected.


Basic types and conversion rules +
APIAccepted values and key options


string()Strings only. trim / min / max / pattern. Length uses UTF-16 code units.
number()Decimal strings and finite numbers. Empty strings follow null presence/default settings. Rejects whitespace, hexadecimal notation, and Infinity. integer requires safe integers.
boolean()Booleans and the strings "true" / "false" / "1" / "0". Rejects numeric 0 / 1.
enum() / literal()enum uses string choices; literal supports fixed string, numeric, and boolean choices.
date()ISO date and date-time strings. Returns a Date; Date objects are not accepted as input. Supports local time, Z, and ±HH:MM.
array()Fields, row objects, or arrays as elements. min / max / wrapScalar.
object()Nested objects and optional / nullable / nullish parents. unknownKeys: strict / strip / passthrough. Object defaults require an explicit target.
transform() / refine()Synchronous conversion and extra validation. Exceptions from user callbacks propagate.
union() / xor()Accept any matching branch, or require exactly one matching branch.
discriminatedUnion() / intersection()Select by a discriminator, or merge both validation outputs.
All field constructors support optional / nullable / nullish / default / description. Date-time strings without a time zone use the runtime's local time.


INPUT ≠ OUTPUT
Types before and after conversion.
Infer Input<typeof query> and Output<typeof query>. For example, page accepts a string, number, or missing value on input and becomes a required number after validation.






04 / INTEGRATIONS
For forms. For CLIs.
Implements Standard Schema v1.
Pass schemas directly to compatible tools.


REACT HOOK FORM
Repeated rows with array(object).
Put a row schema inside an array for line items and product lists. Use it with useFieldArray; error paths such as items → 0 → quantity identify the row.


form.ts
import * as l from 'loculus';
import { useForm } from 'react-hook-form';
import { standardSchemaResolver }
  from '@hookform/resolvers/standard-schema';

const item = l.object({
  name: l.string({ min: 1 }),
  quantity: l.number({ integer: true, gte: 1 }),
});
const form = l.object({
  title: l.string({ min: 1 }),
  items: l.array(item, { wrapScalar: false, min: 1 }),
});

useForm<l.Input<typeof form>, unknown, l.Output<typeof form>>({
  resolver: standardSchemaResolver(form),
});

POLITTY
The same schemas for CLI arguments.
The @politty/loculus adapter adds CLI metadata such as aliases, environment variables, and descriptions alongside value validation.


import * as l from 'loculus';
import { arg, defineCommand }
  from '@politty/loculus';

const serve = defineCommand({
  name: 'serve',
  args: l.object({
    port: arg(l.number({
      integer: true, gte: 1,
      lte: 65535, default: 3000,
    }), { alias: 'p', env: 'PORT' }),
  }),
  run: ({ port }) => console.log(port),
});

06 / SCOPE & LIMITS
Before you use it.
Specializing in input boundaries has limits.
Loculus is not a full application data-modeling library.


A GOOD FIT
Inputs expressed as names and values
CLI options, search queries, and text-focused forms. Define conversions and missing-value handling together in a short schema.
Use array(object) for repeated form rows. The library focuses on flat inputs with selected support for nesting.
ALSO CONSIDER OTHER LIBRARIES
Broader types and asynchronous work
For recursive schemas, Map, Set, tuples, specialized formats, or asynchronous validation, explore Zod and Valibot.
Loculus has its own error representation. Standard Schema support does not make it a direct replacement for code that expects Zod error codes or union error structures.
Zod API ↗Valibot API ↗


Nested form values are supported; recursive schemas are not
Use object({ address: object(...) }) or array(array(...)). Parent optionality and child optionality are independent. Each array level requires an array by default; explicitly set wrapScalar on every level that should wrap scalars.


Defaults bypass constraints and transformations
Defaults are treated as validated outputs. In string({ min: 5, default: 'x' }), a missing value returns 'x' without a length error. Use defaults that satisfy your output contract. Referenced defaults keep their identity.


Inherited properties and schema immutability
Declared fields read ordinary JavaScript properties, including inherited values. Treat schemas and introspection metadata as immutable after creation. Construct a new schema when a definition changes. Declared __proto__ fields are skipped, and passthrough excludes that key.


Runtime and measurement scope
Distributed packages contain JavaScript compiled from TypeScript. The benchmark workflow measures selected cases on Node and Bun. Compare results for your own schemas and environment before drawing performance conclusions.
